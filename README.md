# 2026 제주독서대전 · 책밭 스탬프 투어

참여자 화면(`index.html`)과 관리자 화면(`admin.html`)으로 된 모바일 웹앱입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `config/programs.js` | **프로그램 설정**: 이름·영역·일시·장소·우천 시 장소·인증코드·QR 값·스탬프 대상 여부, 설문 링크, 설문 확인코드, 담당자 PIN, 관리자 비밀번호 |
| `core.js` | 스탬프 규칙 (3개 이상, 5칸, 같은 프로그램 1회, 설문 확인, 교환 처리). 서버와 데모 모드가 함께 써요 |
| `server.js` | 운영용 서버 (Node.js 18 이상, 외부 패키지 없음). 참여자 기록은 `data/db.json`에 저장 |
| `index.html` | 참여자 화면: 시작 → 등록 → 스탬프판 → 만족도 조사 → 교환권, 행사 정보 |
| `admin.html` | 관리자 화면: 실시간 현황, 스탬프 QR·코드 출력, 설문 확인 QR, 프로그램 설정 |
| `demo-serve.ps1` | Node.js 없는 PC에서 화면만 미리 보는 서버 (데모 모드) |

## 운영 (서버 모드)

```bash
node server.js
```

- 참여자: `http://서버주소:8080/` · 관리자: `http://서버주소:8080/admin`
- 포트 변경: `PORT=3000 node server.js`
- 휴대폰 카메라를 앱 안에서 쓰려면 **https 주소**가 필요해요 (Nginx·Cloudflare 등 앞단에서 https 연결).
  https가 아니어도 휴대폰 기본 카메라로 부스 QR을 찍으면 앱이 열리며 바로 스탬프가 찍히고, 4자리 코드 입력도 됩니다.
- `config/` 와 `data/` 폴더는 서버가 밖으로 내보내지 않아요 (코드·PIN 보호).

## 행사 전 체크리스트

1. `config/programs.js` 에서 `adminPassword`, `staffPin`, `survey.code` 를 새 값으로 바꾸기
2. 우천 시 장소(`rainPlace`)와 북마켓 장소 확인해서 채우기
3. 관리자 → 스탬프 QR·코드 탭에서 **참여자 앱 주소**를 실제 https 주소로 넣고 출력 → 각 부스에 비치
4. 관리자 → 설문 확인 QR 탭 출력 → 1층 로비 담당자에게 전달 (확인코드는 담당자만 알기)

## 데모 모드

서버 없이 열면 자동으로 데모 모드가 되고, 기록은 그 브라우저 안에만 저장돼요 (화면 오른쪽 위 "데모 모드" 표시).
데모 관리자 비밀번호는 `config/programs.js`의 `adminPassword` 값이에요.

## 개인정보

닉네임 + 휴대폰 뒷자리 4자리만 받습니다. 같은 닉네임·뒷자리로 다시 들어오면 기록이 이어져요(기기 변경 대응).
행사 종료 후 1개월 안에 `data/db.json` 을 삭제해 주세요 (동의 화면에 안내된 보유 기간).
만족도 조사 응답은 구글 설문지에서 따로 관리돼요.
